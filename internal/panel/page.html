            Web chats
            
  
            ChatGPT, Claude and Gemini in the browser keep your conversations on their servers. Cortex can save them from an export file or, while you chat, through a browser extension. Both end up in the vault like any other source and can be switched off under Sources.
            
  
            
    
            Import an export
            
    
            Choose the file you downloaded: the .zip as it is, or the conversations.json inside it. ChatGPT: Settings, Data controls, Export data. Claude: Settings, Privacy, Export data. An export is a one-off snapshot of that day; import a newer one later to bring a conversation up to date. An import is something you ask for, so it ignores Pause and the source switches.
            
    
            
      
      
    
            
    
            
  
            
  
            
    
            Browser extension
            
    
            Saves the ChatGPT, Claude or Gemini conversation you have open in Chrome, Edge or Brave to this Cortex while you chat. It sends nothing anywhere else.
            
    
    
            
      
      
      
    
            
    
            
    
            To set it up:
            
    
              
      
            1. Find the extension folder in the Cortex repository or release (not in any browser store yet).
              2. 
      
            2. Open chrome://extensions (edge://extensions in Edge), turn on Developer mode, press Load unpacked and choose that folder.
              3. 
      
            3. Open the extension's options, paste the pairing code and the port above, and press Test connection.
              4. 
    
            
    
            Regenerate replaces the code; the extension stops working until you paste the new one.
            
    
            
  
            

  
            Connect your AI tools
            
  
            Cortex can let AI tools search and read your notes through an MCP server. The tool starts it when needed; Cortex does not have to be running, and nothing is written to your notes.
            
  
            
  
            

  
            Turning something off stops capturing it. Notes already written are never deleted.
